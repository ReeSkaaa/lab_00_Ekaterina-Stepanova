## Задание 

Перепишите процедуру Insertion-sort для сортировки в невозрастающем порядке вместо неубывающего с использованием процедуры Swap.

## Input / Output 

| Input                       | Output             |
|---------------------------- |------------------  |

| 4 1 3 7 10 1 4              |                    |
