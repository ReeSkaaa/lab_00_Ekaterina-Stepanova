- **GitHub** — платформа для хостинга репозиториев
- **Markdown** — язык разметки для оформления документации
- **PyCharm** — россплатформенная интегрированная среда разработки для языка программирования Python


### Инструкция по запуску

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ReeSkaaa/algorithms-and-data-structures.git
   ```
2. Перейдите в папку с проектом:
   ```bash
   cd algorithms-and-data-structures/Lab_1
   ```
3. **Запуску всех лабараторных**
    ```bash
    python3 run_code_script.py 
    ```
4. **Запуску всех тестов**
    ```bash
    python3 run_tests_script.py 
   ```
