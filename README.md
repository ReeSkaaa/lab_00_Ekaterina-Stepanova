# Лабораторная работа №0: Введение 
### Цель данной лабораторной работы:
1) попробовать разные способы ввода данных с помощью консоли и с помощью файла
2) научиться оценивать время работы программы с помощью библиотеки time
3) научиться оценивать затраты памяти

### Инструкция по запуску:
Достаточно просклонировать себе ветку lab_0 из репозитория и запустиь проект через какое-нибудь IDE.
Установить библиотеки time и memory_profiler(для теста).

### Структура проекта

<li> папка `task_1` предназначен для первого задания, внутри него лежит папка `src`, она хранит себе файлы с расширением .py, в которых находятся решения для каждой подзадачи.
  
<li> папка `task_2` предназначен для второго задания, внутри него лежит папка `src`, она хранит себе файл с расширением .py, в которых находится решение задачи, а также папка `txtf`, она предназначена для хранения входных и выходных файлов.

<li> папка `task_3` предназначен для третьего задания, внутри него лежит папка `src`, она хранит себе файл с расширением .py, в которых находится решение задачи, а также папка `txtf`, она предназначена для хранения входных и выходных файлов.

<li> папка `task_4` предназначен для четвертого задания, внутри него лежит папка `src`, она хранит себе файлы с расширением .py, в которых находится решение задачи(оценка времени).
