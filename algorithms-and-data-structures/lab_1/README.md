## Инструкция по запуску:

1. Клонирование репозитория:

git clone https://github.com/ReeSkaaa/algorithms-and-data-structures/lab_2

2. Перейдите в папку с проектом:
   cd algorithms-and-data-structures/lab_2
 
3. Запустите программу:
    python src/main.py
   
## Описание структуры проекта:
Проект lab_1 состоит из нескольких папок, каждая из которых отвечает за определенное задание(все папки подписаны номером задания!), внутри каждой папки есть директории(папки):

- `src/` — исходный код программы.
  
- `tests/` — автоматические тесты для проверки работы кода.

- `txtf` - отвечает за хранение текстовых входных и выходных файлов.

Также в lab_1 есть pdf файл Лаб_1_аисд_СтепановаЕА - это отчет по работе

## Тестирование

Для запуска тестов выполните:
```bash
pytest tests/
```
