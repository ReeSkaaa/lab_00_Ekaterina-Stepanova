# Лабораторная работа №1:  Сортировка вставками, выбором, пузырьковая.
## Цель лабораторной работы:
<li> Ознакомиться с сортировками: вставкой, выбором, пузырьковой.
<li> Ознакмиться с линейным поиском.
<li> Оценить их время работы и затрыты памяти.
  
## Инструкция по запуску:

Необходимо из данного репозитория просклонировать папку lab_1.
Запустить в вашем IDE, из дополнительных библиотек нужно установить memory_profiler для оценки затрат памяти.

## Описание структуры проекта:
Проект lab_1 состоит из нескольких папок, каждая из которых отвечает за определенное задание(все папки подписаны номером задания!), внутри каждой папки есть директории(папки):

`src` - отвечает за хранение .py файлов, в которых записано само решение

`tests` - отвечает за хранение .py файлов, в которых прописаны тесты для решений из папки src

`txtf` - отвечает за хранение текстовых входных и выходных файлов.

Также в lab_1 есть pdf файл Лаб_1_аисд_СтепановаЕА - это отчет по работе
